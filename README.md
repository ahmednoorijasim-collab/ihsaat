# الإحصائيات

تطبيق أندرويد لإحصاءات حالات تحديث سجل الناخبين — إدخال يومي من عدة موظفين، موقف أسبوعي وشهري وسنوي، وتصدير Excel.

## الحالات المسجلة
تسجيل جديد · تسجيل + تغيير · تغيير · تغيير بايومتري · تصحيح · حذف · إضافة · بطاقات موزعة (عام / خاص)

## التجهيز (مرة واحدة فقط — يقوم بها مسؤول المكتب)
1. افتح Google Sheets وأنشئ جدولاً جديداً باسم «الإحصائيات».
2. من القائمة: **الإضافات ← Apps Script**. احذف الكود الموجود والصق محتوى الملف `backend/Code.gs`.
3. غيّر السطر `const OFFICE_KEY = 'khanaqin-2026';` إلى رمز خاص بمكتبكم، ثم احفظ.
4. **نشر ← نشر جديد** ← النوع: **تطبيق ويب**.
   - التنفيذ باسم: **أنا**
   - من يمكنه الوصول: **أي شخص**
5. وافق على الأذونات، وانسخ **رابط تطبيق الويب** (ينتهي بـ `/exec`).
6. في التطبيق: الإعدادات ← اكتب اسمك، الرابط، والرمز ← حفظ الإعدادات.
7. اضغط **إرسال رمز الإعداد** وأرسله لزملائك؛ كل موظف يلصقه في تطبيقه ويكتب اسمه.

كل البيانات تُحفظ في نفس جدول Google، فيرى الجميع نفس الأرقام، ويمكن فتح الجدول مباشرة كنسخة احتياطية.

> عند تعديل كود الخادم لاحقاً: نشر ← إدارة عمليات النشر ← تعديل ← إصدار جديد (حتى يبقى نفس الرابط).

## بدون إنترنت
الإدخال يُحفظ على الهاتف ويُرسل تلقائياً عند رجوع الاتصال (يظهر عدّاد «غير مرسل» أعلى الشاشة).

## تحميل التطبيق
كل تحديث على GitHub يبني ملف APK تلقائياً: **Actions ← آخر تشغيل ← Ihsaat-APK**.

## نسخة الآيفون
نفس التطبيق يعمل على الآيفون من المتصفح، ويرتبط بنفس جدول Google فيرى الجميع نفس الأرقام.

**التفعيل (مرة واحدة):** في GitHub افتح المستودع ← Settings ← Pages ← Source: **Deploy from a branch** ← Branch: **main** والمجلد **/docs** ← Save.

**الرابط:** https://ahmednoorijasim-collab.github.io/ihsaat/

**على الآيفون:** افتح الرابط في **Safari** ← زر المشاركة ← **إضافة إلى الشاشة الرئيسية**. بعدها افتح التطبيق من أيقونته، ثم الإعدادات ← اكتب اسمك ← الصق رمز الإعداد.

> مجلد `docs` يتحدّث تلقائياً من ملفات التطبيق، فلا تعدّله يدوياً.
